# YMH219 - Flappy Bird Masaüstü Oyunu

## Proje Adı ve Kısa Açıklama
**YMH219-FlappyBird**, Nesne Tabanlı Programlama (YMH 219) dersi kapsamında C# ve .NET Windows Forms kullanılarak geliştirilmiş masaüstü arcade oyunudur. Tarihi Binbirdirek Sarnıcı sütunları ve dinamik doğa atmosferi eşliğinde tasarlanan oyunda oyuncu, seçtiği kuş karakterini yerçekimi ve engel mekaniklerine karşı kontrol ederek en yüksek skoru elde etmeye çalışır.

## Kullanılan Teknoloji / NuGet Paketleri
* **Programlama Dili:** C#
* **Platform / Framework:** .NET (Windows Forms)
* **Grafik ve Sistem Kütüphaneleri:** `System.Drawing`, `System.Drawing.Drawing2D`, `System.Windows.Forms`, `System.IO`, `System.Media` (Harici NuGet paketi gerektirmez, doğrudan derlenip çalıştırılabilir.)
